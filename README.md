# Python OOP – SoftUni

My solutions to the **Python OOP** course at SoftUni (Software University), covering object-oriented design in Python from classes and inheritance to SOLID principles, decorators and unit testing.

Each topic has two folders: the lab (worked in class) and the exercise (solved independently).

## Topics

| # | Topic | Key concepts |
|---|---|---|
| 01–02 | First steps in OOP | Classes, objects, attributes, methods |
| 03–04 | Classes and objects | Constructors, instance vs class attributes, `__repr__` |
| 05–06 | Inheritance | Single, multiple and multilevel inheritance, `super()` |
| 07–08 | Encapsulation | Private attributes, properties, getters and setters, validation |
| 09–10 | Class and static methods | `@classmethod`, `@staticmethod`, alternative constructors |
| 11–12 | Polymorphism and abstraction | Abstract base classes (`abc`), method overriding, dunder methods |
| 13–14 | SOLID | Single responsibility, open/closed, Liskov, interface segregation, dependency inversion |
| 15–16 | Iterators and generators | `__iter__` / `__next__`, `yield`, generator expressions |
| 17–18 | Decorators | Function decorators, decorators with arguments, `functools.wraps` |
| 19 | Testing | Unit tests with `unittest`, test cases and assertions |
